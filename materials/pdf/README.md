# 参与者下载用 PDF

将 PDF **按下列 exact 文件名** 放入本目录 `materials/pdf/`。  
屏上阅读仍用 `../combined_materials.md`；本目录仅用于「下载」按钮。

---

## 一、培训材料（2 个文件）

| 文件名 | 谁可下载 |
|--------|----------|
| `A组_培训材料.pdf` | **A 组**审讯者（`control`） |
| `B组_SUE理论培训.pdf` | **B / C / D 组**审讯者（共用 SUE 理论） |

- 不含知情同意书  
- **C / D 组 Avatar 组别说明**不提供下载（仅屏上阅读）

---

## 二、案件材料（每种案件 3 个文件，共 6 个）

每种案件（纵火 / 盗窃）准备 **3 个 PDF**：

| 文件名 | 提供给 | 内容建议 |
|--------|--------|----------|
| `纵火案_审讯者材料.pdf` | **审讯者**（配对为纵火案嫌疑人时） | 案件背景 + 全部证据（合并为一份） |
| `纵火案_有罪嫌疑人情景.pdf` | **嫌疑人**（纵火 + 有罪） | 情景扮演文字 |
| `纵火案_无罪嫌疑人情景.pdf` | **嫌疑人**（纵火 + 无罪） | 情景扮演文字 |
| `盗窃案_审讯者材料.pdf` | **审讯者**（配对为盗窃案嫌疑人时） | 案件背景 + 全部证据 |
| `盗窃案_有罪嫌疑人情景.pdf` | **嫌疑人**（盗窃 + 有罪） | 情景扮演文字 |
| `盗窃案_无罪嫌疑人情景.pdf` | **嫌疑人**（盗窃 + 无罪） | 情景扮演文字 |

### 下载规则

- **嫌疑人**：阅读情景材料页可下载；预约成功页、实验完成页可再次下载 **1 个** 有罪/无罪情景 PDF。  
- **审讯者**：完成预约后，若该时段**已有嫌疑人预约**（配对成功），可下载 **1 个** `*案_审讯者材料.pdf`；若尚未配对，提示过段时间重新登录「预约管理」再下载。

## 三、制作 PDF 时可对照的程序内文案

| 用途 | 参考位置 |
|------|----------|
| 审讯者背景 + 证据 | `app.py` → `CASE_INFO["arson"]` / `CASE_INFO["theft"]`（`overview` + `evidence`） |
| 嫌疑人情景 | `app.py` → `ARSON_GUILTY_CONTEXT`、`ARSON_INNOCENT_CONTEXT`、`THEFT_GUILTY_CONTEXT`、`THEFT_INNOCENT_CONTEXT` |
| A 组培训 | `combined_materials.md` → `section:control` |
| SUE 培训 | `combined_materials.md` → `section:theory_sue`（屏上另有 EFM 表，见 `app.py` `_efm_matrix_slide_html`） |
